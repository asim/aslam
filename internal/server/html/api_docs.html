API documentation

Access Aslam's knowledge collections and your account from other applications. OpenAPI JSON · Agent guide · Manage API keys

Authentication

Create a key in Settings → API keys. Send Authorization: Bearer YOUR_KEY. Keys inherit your account permissions and daily question limits. Search remains public. Never put keys in URLs or browser-side code; revoke unused keys in settings.

curl -H 'Authorization: Bearer YOUR_KEY' \
  'https://aslam.org/api/knowledge/browse?collection=quran&group=2&limit=5'

MCP

Connect to https://aslam.org/mcp using Streamable HTTP and the same Authorization header. Tools: collections, contents, browse, search, read. All MCP tools are read-only reference retrieval; no model calls or private account data. Stateless JSON responses; no legacy SSE endpoint.

Pages return next when more data is available. Resolve relative URLs against https://aslam.org. Preserve source attribution when quoting. Default page size is 20, maximum 50. Requests may return 503 when busy; retry with backoff. MCP bodies are limited to 16 KiB. Browser-only settings, signup, administrative actions and device-local reader preferences are not integration APIs.
